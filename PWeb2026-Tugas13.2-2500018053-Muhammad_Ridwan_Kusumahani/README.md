# PWeb 2026 – Tugas 13.2 Penanganan Form di PHP

Aplikasi pengolahan nilai mahasiswa yang menerapkan:
- Penanganan form dengan metode POST dan GET
- Array multidimensi
- Function buatan sendiri
- `array_filter`, `array_column`, `array_sum`, `usort`, dan `count`
- Validasi input
- Session untuk menyimpan data sementara
- Pencarian dan pengurutan data

## Cara menjalankan
1. Pastikan PHP sudah terpasang.
2. Buka terminal pada folder proyek.
3. Jalankan: `php -S localhost:8000`
4. Buka browser: `http://localhost:8000`

## File
- `index.php` – logika PHP dan tampilan aplikasi
- `style.css` – desain antarmuka

Ganti nama folder menjadi: `PWeb2026-Tugas13.2-NIM-NamaMhs` sesuai identitas mahasiswa.
